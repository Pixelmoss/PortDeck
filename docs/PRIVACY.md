# PortDeck Privacy Policy

PortDeck is a local-first developer tool. Service discovery, process management, health checks, logs, configuration and audit history remain on the user's Mac.

PortDeck does not create an account, sell data, use advertising identifiers or automatically upload service commands, paths, logs, diagnostics or crash reports.

Crash diagnostics are disabled by default. If the user explicitly enables local crash diagnostics, macOS and Electron may create crash files on the device. PortDeck does not transmit those files automatically. Diagnostic and configuration exports occur only when the user presses the corresponding export button.

The application may request public GitHub release metadata to check whether a newer version is available. No local service data is included in that request.

For privacy questions, contact the address published on the official PortDeck support page.
