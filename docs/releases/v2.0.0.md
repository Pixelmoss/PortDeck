# PortDeck 2.0 正式版

PortDeck 2.0 将本地服务发现、健康检查、可靠进程管理和日常工作区能力整合成第一套完整的桌面产品体验。

## 主要更新

- 在桌面设置中即时切换简体中文与 English，重启后保持选择。
- Web 界面、macOS 菜单栏、应用菜单、系统通知和更新提示使用同一语言。
- 修复从英文切回中文失败的问题，并补充双向切换自动化测试。
- 支持工作区、服务分组、标签、收藏、排序和批量启停。
- 提供 Node.js、Python、Docker Compose 和静态网站服务模板。
- 加入健康异常与恢复通知、实时日志、风险预览和操作审计。
- 优化 Electron 安装包体积，仅保留中英文运行资源，并加入 CI 体积预算。
- 发布流程自动生成 SBOM、产物清单和 SHA-256 校验和。

## 安装说明

- Apple Silicon Mac 请下载 `PortDeck-2.0.0-arm64.dmg`。
- Intel Mac 请下载 `PortDeck-2.0.0-x64.dmg`。
- 需要同时兼容两种架构时可下载 `PortDeck-2.0.0-universal.dmg`。

若 Release 标记为“预发布”，表示该安装包尚未完成 Developer ID 签名与 Apple 公证，仅用于内部测试。公开安装请使用已签名、公证且通过 Gatekeeper 校验的正式产物。

## 数据与隐私

PortDeck 仅监听 `127.0.0.1`。崩溃诊断默认关闭，配置、日志和诊断信息不会自动上传。
