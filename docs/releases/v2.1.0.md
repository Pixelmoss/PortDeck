# PortDeck 2.1.0

PortDeck 2.1 采用全新的 macOS 原生工具型界面，在不改变现有服务管理能力的前提下，重新组织了状态、服务列表和详情操作。

## 本次更新

- 使用接近 macOS 系统工具的浅色与深色自适应视觉语言。
- 将五张概览卡压缩为紧凑状态条，减少无效占用。
- 服务列表改为服务、端口、健康状态和操作四列结构。
- 新增右侧服务检查器，集中展示运行状态、进程、端口、命令和最近日志。
- 常用启停操作保留在列表行，完整操作集中到检查器。
- 提高核心文字和控件尺寸，改善长名称、路径和小窗口下的可读性。
- 保持工作区、收藏、批量启停、风险预览、历史、通知、更新和中英文切换能力。

## 验证范围

- Node.js 自动测试 54 项全部通过，无跳过
- SwiftUI 原生模块构建通过
- Electron 真实窗口与中英文切换
- ARM64 打包应用使用隔离配置和端口启动通过，服务 API 正常响应
- 服务检查器选择与操作入口
- ARM64 应用包构建、磁盘映像、架构、双语资源和 Bundle 完整性
- DMG 101.6 MB、ZIP 109.5 MB，均通过体积预算

## 安装说明

- Apple Silicon Mac 使用 `PortDeck-2.1.0-arm64.dmg`。
- 未签名内部测试包首次启动时可能需要在系统设置中确认。
