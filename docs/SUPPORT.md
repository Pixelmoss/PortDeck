# PortDeck Support

Before requesting support, open **Desktop Settings → Export diagnostics**. Review the JSON file before sharing it. The report omits full project paths, commands, notes and log contents.

Useful information includes the PortDeck version, macOS version, CPU architecture, the affected service type and the exact error shown in the interface.

Never post API keys, passwords, private source code or full service logs in a public issue.
